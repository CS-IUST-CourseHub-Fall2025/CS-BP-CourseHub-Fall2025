# تحلیل‌گر متن

برنامه‌ای بنویسید که:
1. یک رشته از کاربر دریافت کند
2. تحلیل‌های زیر را روی رشته انجام دهد:
   - آیا رشته با حرف بزرگ شروع می‌شود؟
   - آیا رشته با علامت سؤال پایان می‌یابد؟
   - آیا طول رشته بیشتر از ۱۰ کاراکتر است؟
3. نتایج را نمایش دهد

# مثال

## ورودی
Hello, how are you?
##خروجی

شروع با حرف بزرگ: True  
پایان با علامت سؤال: True   
طول بیشتر از ۱۰ کاراکتر: True
