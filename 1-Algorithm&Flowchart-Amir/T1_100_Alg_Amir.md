# جابجایی اعداد
الگوریتمی بنویسید که با دریافت دو عدد a و b جای آن ها را جابجا کند.

یعنی در انتها عدد a باید در b ذخیره شده باشد و عدد b در a.
## ورودی
دو عدد a و b
## خروجی
جابجا شده‌ی اعداد a و b
## مثال
### ورودی نمونه:
```
a = 0, b = 1
```
### خروجی نمونه:
```
a = 1, b = 0
```
