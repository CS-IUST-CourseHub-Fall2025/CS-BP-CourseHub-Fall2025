##  Resources

- Programming Language: Python  
- Development Environment: VS Code  
- Version Control: Git & GitHub

---

##  Learning Outcomes

By the end of this course, students were expected to:

- Understand fundamental programming concepts and computational thinking  
- Design algorithms and represent solutions using flowcharts  
- Write clean and structured Python programs  
- Work with core data structures and control flow constructs  
- Develop reusable functions and modular code  
- Handle exceptions and perform file operations  
- Build a strong foundation for further computer science studies
