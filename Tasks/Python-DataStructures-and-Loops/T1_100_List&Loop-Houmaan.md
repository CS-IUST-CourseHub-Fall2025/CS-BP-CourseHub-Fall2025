# مهندس شبکه و بازسازی جریان داده

شما یک مهندس امنیت شبکه در یک دیتاسنتر بزرگ هستید و جریانی حیاتی از بسته‌های داده (Data Packets) را دریافت کرده‌اید که حجم هر بسته در آرایه‌ای از اعداد مثبت ذخیره شده است.

سیستم امنیتی فایروال قانون سخت‌گیرانه‌ای دارد: برای عبور امن داده‌ها، **مجموع حجم کل بسته‌ها** باید دقیقاً بر عدد پروتکل **`p`** بخش‌پذیر باشد. در غیر این صورت، کل فایل به عنوان "داده‌ی مخدوش" مسدود می‌شود.

در حال حاضر، مجموع حجم داده‌های دریافتی با این قانون همخوانی ندارد. از آنجا که فرصتی برای دانلود مجدد کل داده‌ها نیست، راه حل شما حذف بخشی از داده‌هاست.

### ماموریت
شما باید **کوچک‌ترین زیرآرایه‌ی متوالی** (Shortest Subarray) را از جریان داده‌ها حذف کنید به طوری که مجموع اعدادِ باقی‌مانده بر `p` بخش‌پذیر شود. هدف نهایی، از دست دادن کمترین مقدار اطلاعات است.

### نکات و محدودیت‌ها
1.  **پیوستگی:** شما فقط مجاز به حذف یک تکه **پیوسته** از آرایه هستید (نمی‌توانید چند عدد پراکنده را حذف کنید).
2.  **ممنوعیت حذف کل:** شما اجازه ندارید **کل آرایه** را حذف کنید. اگر تنها راهِ بخش‌پذیر شدن، حذف تمام اعداد باشد، عملیات غیرممکن تلقی می‌شود.
3.  **خروجی:**
    *   طول کوچک‌ترین زیرآرایه‌ای که باید حذف شود را برگردانید.
    *   اگر هیچ راهی برای رسیدن به خواسته فایروال وجود ندارد (یا مجبور به حذف کل آرایه هستید)، مقدار `-1` را برگردانید.

---
*ورودی شامل آرایه‌ی `nums` و عدد صحیح `p` می‌باشد.*
* در خط اول لیست و در خط دوم عدد p 

## مثال

### ورودی نمونه
```
[3,1,4,2]
6
```
### خروجی نمونه 
```
1
```


### ورودی نمونه
```
[1,2,3]
3
```
### خروجی نمونه 
```
0
```


### خروجی نمونه
