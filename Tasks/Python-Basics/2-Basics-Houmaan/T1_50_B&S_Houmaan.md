# داستان آشپز و کیک طلایی

سرآشپز معروف و خلاق، **بابک**، برای یک جشنواره‌ی غذایی بزرگ، یک شاهکار تهیه کرده است: یک کیک غول‌پیکر که دقیقاً به شکل یک مربع کامل پخته شده است.

هدف **بابک** این است که این کیک را به بیشترین تعداد ممکن از قطعات تقسیم کند تا بتواند مهمانان بیشتری را خوشحال کند. او تصمیم گرفته است که دقیقاً `n` برش روی کیک بزند.


## قوانین برش زدن

قوانین برش زدن **بابک** بسیار دقیق است:

1.  هر برش باید کاملاً **مستقیم** باشد.
2.  هر برش باید یا کاملاً **افقی** (موازی با لبه‌ی بالایی) و یا کاملاً **عمودی** (موازی با لبه‌ی کناری) باشد.
3.  **بابک** به هیچ وجه نباید دو برش را روی هم انجام دهد (یعنی دو برش افقی یا دو برش عمودی در یک مکان یکسان نباشند).
4.  برش‌ها می‌توانند با هم **تقاطع** داشته باشند.


## ورودی (Input)

در تنها سطر ورودی عدد `n` آمده است که نمایانگر تعداد برش‌هایی‌ست که **بابک** می‌خواهد روی کیک بزند.

`1 <= n <= 100`


## خروجی (Output)

تنها سطر خروجی باید شامل تنها یک عدد باشد که برابر با بیش‌ترین تعداد قطعات ممکن برای کیک پس از برش‌های **بابک** است.



## مثال

### ورودی نمونه
```
3
```
### خروجی نمونه 
```
6
```


*   اگر هر سه برش را افقی بزند، کیک فقط به **۴ قسمت** تقسیم می‌شود.
*   اما اگر یک برش افقی و دو برش عمودی بزند، کیک به **۶ قطعه** تبدیل می‌شود!
