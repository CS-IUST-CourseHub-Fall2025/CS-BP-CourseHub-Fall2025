## سامانه‌ی راه آهن

سامانه‌ای مرکزی در حال **رصد حرکت قطارها روی یک مسیر یک‌بعدی** است.
هر قطار در نمایش سامانه با یکی از نمادهای زیر مشخص می‌شود (نقاط در تصویر، ریل قطار را نشان می‌دهند):

* : قطاری که به سمت **راست** در حال حرکت است.
   ```
    ...>...
   ```

* : قطاری که به سمت **چپ** در حال حرکت است.
   ```
    ...<...
   ```

این سامانه در دو لحظه‌ی متوالی از حرکت قطارها، وضعیت مسیر را ثبت کرده است:

* `before` : وضعیت قبل از حرکت
* `after` : وضعیت بعد از حرکت

برنامه‌ای بنویسید که بررسی کند آیا وضعیت دوم (`after`) می‌تواند نتیجه‌ی طبیعی حرکت قطارها از وضعیت اول (`before`) باشد یا خیر.

---

## محدودیت‌ها و قوانین حرکت قطارها:

1. **قطارها نمی‌توانند به عقب حرکت کنند.**


   ```
   before: .>...
   after:  ...>.
   ممکن
   ```

   ```
   before: ...<.
   after:  .<...
   ممکن
   ```

   ```
   before: ....>.
   after:  .>....
   غیر ممکن
   ```

2. **طول مسیر نباید تغییر کند.**

    ```
   before: ...>.......
   after:  .>....
   غیر ممکن
   ```

3. **قطارها نمی‌توانند از روی یکدیگر عبور کنند.**
   در صورتی که دو قطار در جهت مخالف باشند، نباید جای آن‌ها عوض شده باشد.

   مثال:

   ```
   before: .>..<.
   after:  <....>
   غیر ممکن
   ```

4. سامانه در هر لحظه حداکثر دو قطار (و حداقل یکی) را نمایش می‌دهد.
   اگر دو قطار وجود داشته باشند، حتماً در جهت مخالف هم حرکت می‌کنند.

---

## ورودی

ورودی هر دو وضعیت را در یک خط و با یک فاصله میان آنها به شما می‌دهد.

ابتدا وضعیت `before` و با یک فاصله  وضعیت `after` به عنوان ورودی داده می‌شود.

> نکته : برای دریافت ورودی از split استفاده کنید.
 
---


## خروجی:

* اگر وضعیت `after` از نظر قوانین بالا **ممکن** باشد، خروجی:

  ```
  POSSIBLE
  ```

* اگر یکی از قوانین نقض شده باشد، خروجی:

  ```
  IMPOSSIBLE
  ```

---
