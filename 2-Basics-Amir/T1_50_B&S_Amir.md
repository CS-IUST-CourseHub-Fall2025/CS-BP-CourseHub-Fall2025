# عین‌الله کمک میخواد

هفته پیش سر یکی از کلاس های دانشگاه بحث دنباله ها شد. استاد داشت راجع به دنباله های هندسی و حسابی و جمع جملات آنها توضیح میداد؛ اما عین‌الله محاسبه کردن این همه جمع و ضرب براش سخت بود پس تصمیم گرفت برای حل کردن این سوالا یه برنامه بنویسه که از 3 جمله اول دنباله بتونه جمع جملات رو بدست بیاره تا بعدا برای انجام تکالیف ازش کمک بگیره.

## ورودی

ورودی برنامه به شکل مقابله: 
`n:a,b,c`

به طوری که a, b, c به ترتیب جملات اول و دوم و سوم دنباله‌ای هستن که حتما **حسابی یا هندسیه (یا جفتش!)** و n نشون دهنده اینه که چند جمله اولو باید باهم جمع کنی.  
توجه کنید که n عددی صحیحه و جملات، اعشاری هم میتونن باشن.
## خروجی
خروجی باید جمع n جمله اول دنباله **با تقریب به بالا و دقت دو رقم اعشار** باشه.

---
### ورودی نمونه 1
```
3:1,2,4
```
### خروجی نمونه 1
```
7.00
```
---
### ورودی نمونه 2
```
100:1,2,3
```
### خروجی نمونه 2
```
5050.00
```
---
