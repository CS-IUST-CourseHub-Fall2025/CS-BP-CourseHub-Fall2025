# کارنامه‌خوان

یک دیکشنری داده شده که نام دانش‌آموزان و لیستی از نمرات آن‌ها را ذخیره می‌کند.  
وظیفه شما این است که:

1. **میانگین وزنی** هر دانش‌آموز را محاسبه کنید.  
   - وزن نمره iام = i+1 (index از 0 شروع می‌شود)  
2. یک **لیست از تاپل‌ها** بسازید به شکل `(student_name, weighted_average)`  
3. لیست را **نزولی بر اساس میانگین وزنی** مرتب کنید.

### نکته
- فقط از دیکشنری و تاپل استفاده کنید.  
- میانگین وزنی با دقت اعشاری محاسبه شود.

## مثال

# ورودی
در خط اول ورودی n که تعداد دانش‌آموزان را نشان می‌دهد داده می‌شود و در خط های بعد به ترتیب اول اسم دانش‌آموز و در خط زیر آن نمرات آن دانش‌آموز (جدا شده با اسپیس) داده می‌شود.
```
3
Ali
20 18 19
Sara
17 20 16
Reza
15 14 18
```

# خروجی 
```python
[('Ali', 18.833333333333332), ('Sara', 17.833333333333332), ('Reza', 16.833333333333332)]
```

**توضیح مثال**
- وزن علی = (20*1 + 18*2 + 19*3)/(1+2+3) ≈ 18.83  
- وزن سارا ≈ 17.83  
- وزن رضا ≈ 16.83
