# اعتبارسنج رمز عبور

برنامه‌ای بنویسید که:
1. یک رمز عبور از کاربر دریافت کند
2. شرایط زیر را بررسی کند:
   - طول رمز حداقل ۸ کاراکتر باشد
   - شامل حداقل یک حرف بزرگ باشد
   - شامل حداقل یک عدد باشد
   - شامل حداقل یکی از کاراکترهای ویژه (@, #, $) باشد
3. بر اساس شرایط، پیام مناسب نمایش دهد

# مثال
## ورودی
MyPass123
## خروجی

طول مناسب: True   
حرف بزرگ: True    
عدد: True    
کاراکتر ویژه: False
