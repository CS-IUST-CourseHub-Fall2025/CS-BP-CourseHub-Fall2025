# دنباله‌ی فیبوناچی

الگوریتمی بنویسید که با دریافت عدد n از کاربر، nامین جمله دنباله‌ی فیبوناچی را حساب کند.  
در نظر داشته باشید که دو جمله‌ی اول دنباله برابر با 1 هستند.

## ورودی

ورودی عدد صحیح مثبت غیر صفر میباشد.

## خروجی

خروجی nامین جمله دنباله‌ی فیبوناچی است.

## مثال

### ورودی نمونه 1

```
5
```

### خروجی نمونه 1

```
5
```

### ورودی نمونه 2

```
9
```

### خروجی نمونه 2

```
34
```
