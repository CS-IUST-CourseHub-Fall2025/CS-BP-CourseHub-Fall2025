# بررسی‌کننده متن متقارن

برنامه‌ای بنویسید که:
1. یک رشته از کاربر دریافت کند
2. بررسی کند آیا رشته یک "متن متقارن" است یا خیر (متن متقارن متنی است که از هر دو طرف به یک شکل خوانده می‌شود.)
3. خروجی را ("Yes" یا "No")نمایش دهد.
*برنامه باید بزرگی یا کوچکی حروف را نادیده بگیرد.*


# مثال
## ورودی
rAdar
## خروجی
Yes

## ورودی
main
## خروجی
No
