# کیبورد خراب

محسن یک گیمر حرفه‌ای است. او بیست‌وچهار ساعت گذشته را پای بازی گذرانده و حالا که دو ساعت تا ددلاین پروژهٔ دانشگاهی‌اش مانده، متوجه می‌شود کیبوردش خراب شده و بعضی دکمه‌ها خودبه‌خود دوبار یا چندبار فشار داده می‌شوند. در نتیجه هنگام تایپ، حروف اضافی پشت‌سرهم و یکسان ظاهر می‌شوند و متن درست ثبت نمی‌شود.

حال می‌خواهیم برنامه‌ای بنویسیم که متن دریافتی از کیبورد خراب را «تصحیح» کند. قانون تصحیح به صورت زیر است:

* هر مرتبه اگر دو حرف متوالی یکسان دیده شوند، آن دو حرف حذف می‌شوند.( **حروف کوچک** و **حروف بزرگ** متمایزند.)
* این حذف را تکرار می‌کنیم تا دیگر هیچ جفت حرف متوالی یکسانی باقی نماند.

مأموریت شما کمک به محسن است تا قبل از ددلاین رشتهٔ صحیح را به‌دست آورد.

---

## ورودی

یک رشتهٔ غیرخالی شامل حروف انگلیسی (بدون فاصله).

---

## خروجی

در تنها خط خروجی، رشتهٔ نهاییِ تصحیح‌شده (پس از انجام تمامی حذف‌ها) را چاپ کنید. اگر رشتهٔ نهایی خالی شود، خط خالی چاپ کنید.

---

## مثال

### ورودی نمونه 1

```
AssassinsCreed
```

### خروجی نمونه 1

```
AainsCrd
```

**توضیح:**
AssassinsCreed → AassinsCreed → AainsCreed → AainsCrd


### ورودی نمونه 2

```
HollowKnight
```

### خروجی نمونه 2

```
HwKnight
```
