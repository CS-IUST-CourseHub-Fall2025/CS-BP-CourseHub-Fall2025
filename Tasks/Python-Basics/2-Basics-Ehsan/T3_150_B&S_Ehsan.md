# ساحره‌ی خبیث

هری به تازگی در **مدرسه‌ی جادوگری** قبول شده و می‌خواهد یک **معجون جادویی** بسازد. برای این کار، باید **دمای مناسب معجون** را بداند.

اما **ساحره‌ای خبیث** که قرار است به او کمک کند، می‌خواهد هری را گمراه کند! او دما را به صورت مرموز و با قوانین خاص خودش به هری می‌گوید. هری باید باهوش باشد و **منطق جادویی دما** را کشف کند تا معجونش خراب نشود.

----------

## ورودی

یک رشته شامل:

-   یک عدد صحیح یا اعشاری
    
-   یک حرف واحد `C` یا `F` که میتواند کوچک یا بزرگ باشد
    
-   ممکن است با یک یا چند علامت یا نویسه عجیب پایان یابد



 
**مثال‌ها:**

```
25C
77F
5C!
100F#

```

----------

## خروجی

1.  **تبدیل واحد دما:**
    
    -   اگر آخرین حرف `C` یا `c` باشد ← دما همان سلسیوس است.
        
    -   اگر آخرین حرف `F` یا `f` باشد ← دما را به سلسیوس تبدیل کنید:  
        C = (F - 32) /1.8
	      - البته نیازی نیست نگران دمای منفی باشید چون هری خودش ‌می‌دونه که آب زیر 0 درجه یخ می‌زنه!
    -  اگر با یک علامت یا نویسه عجیب پایان یابد خروجی به صورت زیر است :
        
        ```
        what a witch!
        ```
        
2.  **میزان خطا :**
اگر دمای محاسبه شده به سلسیوس رند نباشد میزان خطا از این رابطه بدست می‌آید:
    -   اگر دمای ورودی مثبت و **رقم دهگان آن زوج** باشد یا تک رقمی باشد ← دمای نهایی =   پس از تبدیل به سلسیوس به بالا رند کنید
        
    -   اگر دمای ورودی مثبت و **رقم دهگان آن فرد** باشد ← دمای نهایی = پس از تبدیل به سلسیوس به پایین رند کنید
    
        
3.  **محاسبه وضعیت دما برای ساخت معجون:**
در خروجی دمای نهایی را (با یک فاصله) همراه با وضعیت نمایش دهید:
    -   اگر دمای نهایی بین 10 تا 45 درجه سلسیوس باشد(بازه ی بسته) خروجی به صورت زیر است :
        ```
        25C just fine!
        ```
        
    -   اگر دمای نهایی کمتر از 10 درجه باشد (بازه‌ی باز) خروجی به صورت زیر است:
        ```
        9C too cold!
        ```
        
    -   اگر دمای نهایی بیشتر از 45 درجه باشد (بازه‌ی باز) خروجی به صورت زیر است :  
        ```
        55C too hot!
        ```
