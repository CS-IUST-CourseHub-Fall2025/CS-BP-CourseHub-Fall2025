برنامه‌ای بنویسید که حاصل **n جمله‌ی اول** سری زیر را به ازای x ورودی حساب کند.

![توضیح تصویر](https://s6.uupload.ir/files/formol_4w16.png)

# ورودی

در تنها خط ورودی، دو عدد x و n با فاصله از همدیگر می‌آیند.

# خروجی

شما این سری را تا n جمله حساب می‌کنید و در خروجی پاسخ نهایی را چاپ می‌کنید.

خروجی را با  **دقیقا تا پنج رقم اعشار** حساب کنید تا تمامی تست‌ها پاس شوند.



## مثال


### ورودی نمونه ۱
```
1 3
```

### خروجی نمونه ۱
```
5.50000
```

### ورودی نمونه ۲
```
1.5 3
```

### خروجی نمونه ۲
```
1.74419
```
