#رمز صندوق گنج

## محدودیت‌ها
- زمان: 1 ثانیه
- حافظه: 256 مگابایت
- از تابع بازگشتی استفاده کنید


شما یک کاشف گنج هستید که یک صندوق قدیمی پیدا کرده‌اید. این صندوق با یک قفل عددی خاص قفل شده است. برای باز کردن قفل، باید یک رشته از اعداد را پیدا کنید که:

- از اعداد 1 تا N استفاده کنید (هر عدد فقط یک بار)
- مجموع اعداد انتخابی دقیقاً برابر با S باشد
- باید تعداد تمام حالت‌های ممکن را بشمارید

به عبارت دیگر، چند زیرمجموعه از اعداد 1 تا N وجود دارد که مجموع‌شان برابر S باشد؟

## ورودی
- یک خط حاوی دو عدد N و S که:
  - 1 ≤ N ≤ 30
  - 1 ≤ S ≤ 500

## خروجی
تعداد زیرمجموعه‌هایی که مجموع‌شان برابر S است.


## مثال ۱
### ورودی
```
5 7
```

### خروجی
```
3
```

### توضیح
سه زیرمجموعه وجود دارد:
1. {7} - خود عدد 7 (اما 7 > 5، پس این نامعتبر است)
2. {2, 5} = 7
3. {3, 4} = 7
4. {1, 2, 4} = 7

پس جواب 3 است (زیرمجموعه‌های 2، 3، 4).

## مثال ۲
### ورودی
```
4 6
```

### خروجی
```
2
```

### توضیح
دو زیرمجموعه وجود دارد:
1. {2, 4} = 6
2. {1, 2, 3} = 6
