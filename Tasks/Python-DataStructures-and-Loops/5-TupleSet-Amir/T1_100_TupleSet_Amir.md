# عبدالرشید بی برنامه
عبدالرشید بعد از اینکه یه شکست سنگین در شطرنج رو به عین‌الله تحمیل کرد، از خوشحالی بیش از حد و به بهونه این برد، روزاشو به بیخیالی میگذروند و برنامه روزانه دیگه براش اهمیتی نداشت.  
حالا که چند روز از اون مسابقه گذشته، عبدالرشید تصمیم گرفته برنامش رو دوباره مرتب کنه و نظم بگیره.

جدولی که الان به عنوان برنامه عبدالرشید در نظر گرفته شده یه مقدار نامرتبه و شما باید کمکش کنید که برنامش رو مرتب کنه تا تکلیف هرروزش مشخص بشه.


مرتب سازی دو قانون داره:
+ یک کار مشخص نمیشه توی دو روز مختلف تکرار بشه و حتی در خود روز، دو بار تکرار بشه.
+ اگر بشه کاری رو  به روزای بعدی انداخت، بندازش برای روزای بعد!

## ورودی
ورودی برنامه یک دیکشنریه که یه برنامه نامرتبه.  
شما میتونید ار تابع داخلی `eval()` برای خوندن مستقیم دیکشنری استفاده کنید.

## خروجی
خروجی برنامه باید برنامه مرتب شده‌ی عبدالرشید به شکل یک دیکشنری باشه.

توجه کنید که مقادیر اولیه دیکشنری باید از کوچک به بزرگ مرتب شده باشند و ترتیب کار های هرروز (عناصر درون لیست)
باید حفظ شده باشد.

## مثال
### ورودی نمونه 1
```
{'1': ['A', 'B', 'C'], '2': ['A', 'B', 'D', 'A']}
```
###  خروجی نمونه 1
```
{'1': ['C'], '2': ['A', 'B', 'D']}
```
روز ۱: باتوجه به اینکه A و B در روز دوم هستند، فقط C باقی می ماند

روز ۲: باتوجه به اینکه A دوبار تکرار شده است، A دوم حذف شده و باقی کار ها باقی می مانند.

### ورودی نمونه 2
```
{'432': ['A', 'A', 'B', 'D'], '53': ['L', 'G', 'B', 'C'], '236': ['L', 'A', 'X', 'G', 'H', 'X'], '11': ['P', 'R', 'S', 'D']}
```

```
{'11': ['P', 'R', 'S'], '53': ['C'], '236': ['L', 'X', 'G', 'H'], '432': ['A', 'B', 'D']}
```
