
# محاسبه ب.م.م

با دریافت دو عدد صحیح مثبت، وظیفه شما این است که الگوریتمی پیاده سازی کنید که ب.م.م دو عدد را حساب کرده و خروجی را به کاربر نمایش دهد.

## ورودی

ورودی دو عدد صحیح مثبت بزرگتر از 1 می‌باشد.

## خروجی

خروجی تنها یک عدد صحیح مثبت، حاصل از ب.م.م دو عدد است.

## مثال

### ورودی نمونه ۱

```
72 36
```

### خروجی نمونه ۱

```
36
```

### ورودی نمونه ۲

```
45 60
```

### خروجی نمونه ۲

```
15
```
