#هومان و معمای باغ اعداد

هومان، ریاضیدان جوان اصفهان، در باغ قدیمی پدربزرگش یک سنگ مرموز پیدا کرد. روی سنگ نوشته شده بود:

*"ای جوینده دانش، برای گشودن در خزانۀ دانایی، این اعداد را از کاربر بگیر و محاسبات را انجام ده:"
- عدد اول (a) را از کاربر بگیر
- عدد دوم (b) را از کاربر بگیر  
- یک متن (text) از کاربر دریافت کن
- سپس این رازها را بگشا*.

## صورت سوال

برنامه‌ای بنویسید که:

1. سه متغیر ایجاد کند و مقادیر آن را از کاربر دریافت کند:
   - `a`
   - `b`
   - `text` با مقدار رشته‌ای

2. عملیات زیر را انجام دهد:
   - جمع: `a + b`
   - ضرب: `a * b`
   - تقسیم صحیح: `a // b`
   - توان: `a ** 2`

3. نتایج را همراه با نوع داده‌شان چاپ کند
4. از قالب‌بندی f-string برای تمام خروجی‌ها استفاده کند

# ورودی

ورودی شامل سه متغیر `a` و `b` و `text` است.

# خروجی

خروجی شما باید شرایط صورت سوال را رعایت کند.
