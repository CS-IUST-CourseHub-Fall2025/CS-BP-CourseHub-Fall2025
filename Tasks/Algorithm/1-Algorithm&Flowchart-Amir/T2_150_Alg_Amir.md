# محاسبه فاکتوریل
الگوریتمی بنویسید که با دریافت عدد n، فاکتوریل آن را محاسبه کند. (!n)
## ورودی
ورودی عدد صحیح نامنفی n می باشد.
## خروجی
خروجی الگوریتم باید فاکتوریل عدد n باشد.
## مثال
### ورودی نمونه 1:
```
0
```
### خروجی نمونه 1:
```
1
```
---
### ورودی نمونه 2:
```
4
```
### خروجی نمونه 2:
```
24
```
---
