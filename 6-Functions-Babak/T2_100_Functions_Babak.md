#مسیر جادوگر


## محدودیت‌ها
- زمان: 1 ثانیه
- حافظه: 256 مگابایت
- از تابع بازگشتی استفاده کنید
- اگر خانه شروع یا پایان مسدود باشد، جواب 0 است


شما یک جادوگر هستید که می‌خواهید از گوشه بالا-چپ یک شبکه جادویی N×M به گوشه پایین-راست برسید. در این شبکه:

- برخی خانه‌ها دارای موانع هستند (با # نشان داده می‌شوند)
- برخی خانه‌ها خالی هستند (با . نشان داده می‌شوند)
- شما تنها می‌توانید به سمت راست یا پایین حرکت کنید
- باید تعداد تمام مسیرهای ممکن از شروع تا پایان را بشمارید

## ورودی
- خط اول: دو عدد N و M (ابعاد شبکه) که 1 ≤ N, M ≤ 20
- N خط بعدی: هر خط شامل M کاراکتر ('.' یا '#')

## خروجی
تعداد مسیرهای ممکن از گوشه بالا-چپ به گوشه پایین-راست.


## مثال ۱
### ورودی
```
3 3
...
.#.
...
```

### خروجی
```
2
```

### توضیح
دو مسیر وجود دارد:
1. راست → راست → پایین → پایین
2. پایین → پایین → راست → راست

## مثال ۲
### ورودی
```
2 3
...
...
```

### خروجی
```
3
```

### توضیح
سه مسیر ممکن است.
